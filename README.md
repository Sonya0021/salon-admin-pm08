# Админ-панель парикмахерской «Стиль» (ПМ.08 — Вариант 6)

Веб-приложение с административной панелью для управления услугами стилистов, мастерами, клиентами, записями, пользователями и журналом действий.

## Стек технологий
- **Backend:** Python 3, Flask, Flask-SQLAlchemy, Flask-Login, Werkzeug
- **Frontend:** HTML5, CSS3, Jinja2, JavaScript
- **База данных:** SQLite (`salon_admin.db`)

## Установка и запуск
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Скопируйте `.env.example` в `.env` (опционально, по умолчанию используются стандартные настройки).
3. Заполните базу тестовыми данными:
   ```bash
   python seed.py
   ```
4. Запустите сервер:
   ```bash
   python app.py
   ```
5. Откройте в браузере: `http://127.0.0`

## Тестовые учетные записи
- **Администратор (`admin`):** `admin@salon.local` / `Admin123!` (полный доступ)
- **Менеджер (`manager`):** `manager@salon.local` / `Manager123!` (CRUD рабочих разделов + журнал)
- **Наблюдатель (`viewer`):** `viewer@salon.local` / `Viewer123!` (только просмотр)
